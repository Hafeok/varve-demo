# Architecture decisions

Format, numbering and the change rule are in
[0001](0001-record-architecture-decisions.md). An accepted ADR is not edited;
it changes by a dated amendment or a superseding ADR. Every ADR in force has a
decision set in [`docs/decisions/`](../decisions/).

`docs/brief.md` is the authority, and `docs/spec/script.md` is the
specification these decisions serve.
